# Lançamento — Instrumento Lúdico-Pedagógico (42)

**Status atual: pré-lançamento, em validação física.**

Este documento explica, em linguagem simples, em que estágio o projeto está agora. Não é dirigido a programadores — para detalhes técnicos, consulte o [`CHANGELOG.md`](CHANGELOG.md) ou o [checklist de validação](VALIDATION.md).

---

## O que isso significa

O projeto ainda não tem uma versão 1.0 lançada. Existe um exemplar físico construído e funcionando, com a documentação, o firmware e a interface completos — mas parte da validação final, feita com o instrumento físico na bancada, ainda está em andamento. Uma versão 1.0 só é declarada depois que essa validação estiver inteiramente concluída e revisada.

Isso não é uma formalidade. Este projeto adota como regra não afirmar mais do que pode comprovar — o mesmo princípio que está descrito em [`concept/escopo_e_limitacoes.md`](concept/escopo_e_limitacoes.md). Declarar uma versão 1.0 antes da hora seria romper essa regra.

## O que já está pronto

- A documentação completa do projeto — conceito, arquitetura, hardware e software — está escrita e aprovada.
- O firmware dos quatro módulos do instrumento está implementado e passa em todos os testes automatizados.
- A maior parte dos critérios de validação com o instrumento físico já foi verificada e aprovada.

## O que ainda está em validação

- Uma pequena parte dos critérios de aceitação ainda não tem teste físico registrado.
- A paleta de cores das zonas precisa ser reconfirmada com uma criança do público-alvo (5 anos) — o teste até agora foi feito com um adulto.
- Um ponto da cablagem de um exemplar específico foi montado com material disponível fora da especificação original; eletricamente validado, mas registrado para correção em novos exemplares.

Nenhum desses pontos compromete o uso supervisionado do exemplar atual por um profissional habilitado — mas todos precisam ser fechados antes de o projeto ser chamado de versão 1.0.
